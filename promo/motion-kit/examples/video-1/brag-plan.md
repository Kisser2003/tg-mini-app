# Видео 1 — «Приложение, которое приятно трогать»

**Формат:** 9:16, 1080×1920, 23 с, 30 fps. Стиль серии (как ролик JEEP v2): тёмный фон, серо-белый текст, плоская карточка экрана, зерно.
**Что в кадре:** настоящая разметка и CSS приложения из ветки `claude/ecstatic-clarke-3b94n6` (снимки DOM живого приложения), анимации — с параметрами из кода:
- CSS-анимации (`omf-stagger-in`, `omf-sticker-slap`, `omf-page-enter`, `omf-step-enter`, `omf-cover-in`, `omf-reveal`) проигрываются покадрово;
- пружины framer-motion: пилюля фильтра 520/40, индикатор таба 500/40, шторка 300/30;
- кривая приложения `cubic-bezier(0.22, 1, 0.36, 1)`.
Данные — демо-релизы SAKRON (JEEP + 5 иллюстративных), подставлены вместо API, боевая база не трогается.

| Время | Сцена | Подпись |
|---|---|---|
| 0–3.3 | Хук + библиотека: плитки-конверты каскадом снизу, наклейки «отклонён» / «принят» шлёпаются | «Каждый тап — / как в нативном приложении.» |
| 3.3–6.8 | Фильтры: тап «На проверке» → «Отклонены», пилюля перелетает (вибрация на обоих тапах) | Фильтры |
| 6.8–9.4 | Тап «Помощь»: экран поднимается, полоска таба переезжает | Меню |
| 9.4–13.3 | Мастер: прокрутка → «Дальше» → шаг 2 въезжает справа, сегмент прогресса дорисовывается («Шаг 2 из 4: обложка») → «← Паспорт», шаг 1 въезжает слева | Мастер релиза |
| 13.3–16.3 | Тап по отклонённому «Ночной рейс» → шторка «Почему релиз отклонён» | Если вернули |
| 16.3–20.7 | «Готово»: обложка поднимается, наклейка «на проверке» шлёпается (вибрация в момент удара, 720 мс), проявляется «Отправлено на проверку» | Отправлено |
| 20.7–23 | Финальная карточка: «omf · выпуск музыки прямо из Telegram», @OMF_Distribution_BOT | — |

**Музыка:** ждём трек от пользователя; тапы и смены сцен выровняю по битам.
